# 票据管理

## 应收票据

## 票据贴现
- https://127.0.0.1/receivablebill/page
```json
{
  "billTypeCode_EQ": "001",
  "queryType": "5"
}
```

```sql
select  * 
from `ldg_bill_account` 
where (`finance_type` is null or `finance_type` = '')
	and (`pool_type` = '1'  or `pool_type` is null or `pool_type` = '')
	and `bill_type_code` = '001'
	and `data_source` = '1'
	and `bill_type_code` = '001'
	and `bill_status` in ('001', '005')
	and `enabled_flag` = '0'
	and `group_id` = 'af4ce58b58c721b9dcde3137322e0004'
order by `create_date` desc, `id` desc
limit 20
```

## 票据背书
- https://127.0.0.1/receivablebill/page
```json
{
  "billTypeCode_EQ": "001",
  "queryType": "2"
}
```
```sql
select *
from `ldg_bill_account` 
where (`finance_type` is null or `finance_type` = '')
	and (`pool_type` = '0' or `pool_type` = '1' or `pool_type` is null or `pool_type` = '')
	and `bill_type_code` = '001'
	and `data_source` = '1'
	and `bill_type_code` = '001'
	and `bill_status` = '001'
	and `enabled_flag` = '0'
	and `group_id` = 'af4ce58b58c721b9dcde3137322e0004'
	and `available_amount` > 0.0
```
