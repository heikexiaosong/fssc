### 【定时器】同步银企直连回单附件
- cn.ztessc.service.task.JobCenter#syncdownloadReceipt
- FMS_ELECTRONIC_RECEIPT_UPLOAD: 电子回单下载记录表
```sql
-- 1. 查询银行下的可同步回单的账号数量
select count(1)
from fms_account fav
where 1 = 1
  and fav.E_BANK_MONOBLOCK = '0' -- 网银直联(开通、未开通).
  and fav.SALES_MARK <> '1' -- 销户标志(正常、销户).
  and fav.enabled_flag = '0'
  and fav.validity_flag = '0'
  and fav.BANK_HEAD_ID in ('203')

-- 2. 查询账号对应的回单记录
select *
  from fms_electronic_receipt
 where (payer_bank_account_num in (:bankAccountNumList) or gather_bank_account_num in (:bankAccountNumList))
   and enabled_flag = '0'
   and (fmselectro0_.sync_file_url is null or fmselectro0_.sync_file_url= '') 
   and transaction_date>= '2026-05-18 00:00:00' 
   and transaction_date<= '2026-05-20 00:00:00'

```



### 【页面】同步附件
- 【fms】 https://127.0.0.1/fmselectronicreceipt/downloadReceipt
- cn.ztessc.controller.payment.FmsElectronicReceiptCoreController#downloadReceipt
```json
{
  "bankHeaderCode": "308",
  "bankNumber": "757903254710811",
  "startTransactionDate": "2026-09-05",
  "endTransactionDate": "2026-09-06"
}
```

```sql
-- 查询需要同步附件的回单
select * 
from fms_electronic_receipt fmselectro0_
where (fmselectro0_.payer_bank_account_num in ('757903254710811')
                or fmselectro0_.gather_bank_account_num in ('757903254710811'))
        and fmselectro0_.enabled_flag = '0'
        and (fmselectro0_.sync_file_url is null)
        and fmselectro0_.transaction_date >= TIMESTAMP '2026-09-05 00:00:00.000'
        and fmselectro0_.transaction_date <= TIMESTAMP '2026-09-06 23:59:59.999'
```
