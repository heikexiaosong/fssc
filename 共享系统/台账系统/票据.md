# 票据


### 提示承兑-签收
- ldgfmsbillaccount/promptAcceptanceCancel
- billIds: 票据id列表
```sql
update LDG_BILL_ACCOUNT set  ACCEPT_ABLE = 'Y', OPERATION_ABLE = 'Y' where id in (:billIds)
```

### 提示收票-签收
- ldgfmsbillaccount/promptReceiptCancel
- billIds: 票据id列表
```sql
update LDG_BILL_ACCOUNT set  RECEIVE_ABLE = 'Y', OPERATION_ABLE = 'Y' where id in (:billIds)
```
