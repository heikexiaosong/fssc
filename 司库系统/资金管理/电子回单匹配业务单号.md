#### 【定时器】 电子回单匹配业务单号
- cn.ztessc.service.task.JobCenter#synEleMatchBoe

隐式前置条件:
- 回单已和流水关联
- 流水和业务单已关联

流程:
1. 查询待处理回单列表
2. 根据回单  BATCH_NUMBER_SYS（=流水id） 查询当日/历史流水
3. 根据查询到的流水中的【FMS_BUSINESS_NO】查询业务关联表（FMS_TRANSACTION_DETAILS_BUS）

##### 电子回单匹配业务单号 > 伪代码
查询未完成单据匹配的电子回单，最多100条
for receipt:
    boeMatchTime += 1

    detail = 当日/历史交易明细中 ID = receipt.BATCH_NUMBER_SYS 的数据
    if detail 不存在:
        boeMatchMark = 2
        continue

    busList = 交易明细业务关联表中
              FMS_BUSINESS_NO = detail.FMS_BUSINESS_NO
              and BUS_TYPE in (3,4,5)
              and ENABLED_FLAG = 0

    if busList 为空:
        用 detail.BUS_NO 按 ^ 拆单号，直接写关联表
        boeMatchMark = 1
    else:
        若为付款，需 detail.BOE_MATE_FLAG = Y
        或 detail.MATCH_TIME 超过配置次数
        通过后写 busList 对应关联表
        boeMatchMark = 1
