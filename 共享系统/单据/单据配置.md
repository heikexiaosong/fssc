# 单据配置

### 获取单据配置
- 【BASE】https://127.0.0.1/boepagetemplate/getTemplate
```json
{
    "boeTypeCode": "HUASHI_NBJKSQD1020",
    "groupId": "af4ce58b58c721b9dcde3137322e0004"
}
```

1. 从redis中取
2. 从数据库中取最大版本: SELECT * FROM sys_boe_page_template where BOE_TYPE_ID  =  'd5ae4d47-b3c7-42e1-b153-62e29250bdfe'

### 获取单据模板配置
- 【BASE】https://127.0.0.1/boepagetemplate/findByVersionAndBoeTypeId


### 保存单据配置
- 【BASE】https://127.0.0.1/boepage

```sql
-- 单据区域
-- {
-- 		"ID" : "282c82e6-bd0f-4f5b-a1cc-54587933087e",
-- 		"BOE_TYPE_ID" : "d5ae4d47-b3c7-42e1-b153-62e29250bdfe",
-- 		"BOE_BLOCK" : "quota",
-- 		"BOE_BLOCK_VIEW_NAME" : "关联用信"
-- }
select * from SYS_BOE_PAGE where BOE_TYPE_ID  =  'd5ae4d47-b3c7-42e1-b153-62e29250bdfe'



-- 单据区域字段配置
select * from sys_boe_page_field where BOE_PAGE_ID  = '282c82e6-bd0f-4f5b-a1cc-54587933087e'
```

保存时， 传参： extendConfig 和 prev
{
  "extendConfig": '{"prev":{"endDate":"fmsBase.closingDate","leId":"boeHeader.leId","financingCreditBudgetType":"singleBreed.financingCreditBudgetType","singleCreditBreed":"singleBreed.singleCreditBreed","startDate":"fmsBase.openBankDate"}}',
  "prev": {
      "endDate": "fmsBase.openBankDate",
      "leId": "boeHeader.leIdFms",
      "startDate": "fmsBase.openBankDate"
  }
}
准换成 数据库字段： extendParams
