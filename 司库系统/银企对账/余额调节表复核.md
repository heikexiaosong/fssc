# 余额调节表


### 列表查询
- 【fms】 http://127.0.0.1/fmsbalanceadjustment/page
- cn.ztessc.controller.reconciliation.FmsBalanceAdjustmentReviewCoreController#list
```json
{
  "orgPermissionType": "2",  // 1: 本级; 2: 本级及下级
  "query": [{"code":"bankNumber","condition":3,"fieldType":1,"value":"942007010127536673"}]
```

```sql
--
select
	*
from
	fms_balance_adjustment fmsbalance0_
where
	fmsbalance0_.bank_number like '%942007010127536673%'
	and fmsbalance0_.enabled_flag = '0'
	and fmsbalance0_.data_status = '2'
	and fmsbalance0_.group_id = 'af4ce58b58c721b9dcde3137322e0004'
```

授权： AUTH_TYPE_6("6"): 银企对账模块.-账户初始化

```sql
select
	*
from
	fms_balance_adjustment fmsbalance0_
where 1=1 
	and (fmsbalance0_.status = '2' or fmsbalance0_.status = '4')
	and fmsbalance0_.enabled_flag = '0'
	and fmsbalance0_.data_status = '2'
	and fmsbalance0_.group_id = 'af4ce58b58c721b9dcde3137322e0004'
	and exists (
		select 1 
		from
			fms_pool_org fmspoolorg1_
		    cross join fms_pool_reorg fmspoolreo2_
		where
			fmspoolreo2_.org_id = fmspoolorg1_.id
			and fmspoolorg1_.org_type = '2'
			and fmspoolorg1_.enabled_flag = '0'
			and fmspoolorg1_.validity_flag = '0'
			and fmspoolreo2_.le_id = fmsbalance0_.le_id
			and (fmspoolorg1_.id = 'aa5cbaa2ffffdb8a9997be34b1b7b2ae0e57' or fmspoolorg1_.fid like '%/aa5cbaa2ffffdb8a9997be34b1b7b2ae0e57%') 
	)
```
