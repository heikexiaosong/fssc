# 付款申请单匹配应付票据并更新付款状态
### 【定时器】付款申请单匹配应付票据并更新付款状态
- cn.ztessc.service.task.JobCenter#paymentBoeMatchBillAndPaymentStatus

1. 匹配票据：paymentBoeMatchBill
```sql
select *
from fms_payment_apply_header H
where H.boe_type_code = 'PAYMENT_BOE'
  and H.payment_status in ('10', '20')
  and H.PAYMENT_MODE_CODE in ('5', '16')
  and not exists (
          select 1
          from fms_payment_apply_bill b
          where b.BOE_ID = h.id
  )
  and H.enabled_flag = '0'
order by H.create_date asc, id desc
limit 101

-- 付款申请单关联的出票申请单
select *
from fms_boe_payment_apply fmsboepaym0_
where fmsboepaym0_.apply_boe_id in ('554030b5-52a0-4c68-924f-eab7ede14493'')
  and fmsboepaym0_.enabled_flag = '0'

-- 出票申请单
select *
from fms_boe_header fmsboehead0_
where fmsboehead0_.id in ('c80d16eb-b030-4ffc-aa6d-e7156e1271fc')
  and fmsboehead0_.business_type = '1'  -- 出票申请： 1; 背书申请: 2
  and fmsboehead0_.enabled_flag = '0'
```

2.  更新支付状态：paymentBoeUpdatePaymentStatus
```sql
select *
from fms_payment_apply_header H
where H.boe_type_code = 'PAYMENT_BOE'
  and H.payment_status in ('10', '20')
  and H.PAYMENT_MODE_CODE in ('4', '5', '15', '16')
  and exists (
          select 1
          from fms_payment_apply_bill b
          where b.BOE_ID = h.id
  )
  and H.enabled_flag = '0'
order by H.create_date asc, id desc

-- 付款申请单关联的票据信息
select *
from fms_payment_apply_bill fmspayment0_
where fmspayment0_.boe_id in ('145042fe-2fc8-4df9-9cdc-ec9495509c30')
  and fmspayment0_.enabled_flag = '0'

-- 指令信息
select *
from fms_payment_instructions fmspayment0_
where fmspayment0_.boe_id in ('145042fe-2fc8-4df9-9cdc-ec9495509c30')

```
