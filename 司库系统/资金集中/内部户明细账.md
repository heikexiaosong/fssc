# 内部户明细账


###  列表查询
- https://127.0.0.1/fmsInteriorDetail/queryPageDetail
```json
{
  "orgPermissionType": "1",
  "bankNumber": "HBZ2006001-01", // 内部户账号
  "businessBoeNo": "HUASHI-FMS2607070018", // 业务单号
}
```

```sql
-- 明细账
select *
from FMS_INNER_ACCOUNT a
         inner join FMS_INTERIOR_DETAIL b on a.ID = b.INNER_ACCOUNT_ID
where 1 = 1
  and a.bank_number like '%HBZ2006001-01%'
  and b.business_date >= TIMESTAMP '2026-07-20 00:00:00.000'
  and b.business_date <= TIMESTAMP '2026-08-07 23:59:59.999'
  and b.business_boe_no like '%HUASHI-FMS2607070018%'
  and b.ENABLED_FLAG = '0'
  and b.GROUP_ID = 'af4ce58b58c721b9dcde3137322e0004'
order by BANK_N UMBER asc, business_date asc, last_update_date asc, id asc limit 20
```
