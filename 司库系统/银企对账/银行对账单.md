### 对账中查询
- 【fms】 http:/127.0.0.1/fmsreconciliationflow/page
- cn.ztessc.controller.reconciliation.FmsReconciliationFlowCoreController#list
- 授权： AUTH_TYPE_6("6"): 银企对账模块.-账户初始化
```json
{
  "bankNumber": "942007010127536673"
}
```

```sql
--
select
	*
from
	fms_balance_adjustment fmsbalance0_
where
	fmsbalance0_.bank_number = '942007010127536673'
	and fmsbalance0_.status in ('1', '5')
	and fmsbalance0_.data_status = '2'
	and fmsbalance0_.enabled_flag = '0'
	and fmsbalance0_.group_id = 'af4ce58b58c721b9dcde3137322e0004'
order by
	fmsbalance0_.create_date desc,
	fmsbalance0_.id desc
```
