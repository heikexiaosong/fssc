# 出票申请单据

### 承兑人信息(银承)
承兑人类型为银行时，承兑人账号不应该取大行编码，应该取承兑人联行号。

承兑人类型: 银行
承兑人账号: 支行编码
承兑人户名: 支行名称（开户行名称）
承兑人开户行: 开户行名称

acceptorBankUnitedCode: 承兑人开户行银联号
acceptorBank: 承兑人开户行
acceptorAccountNum: 承兑人账号
acceptorName：承兑人
acceptorType：承兑人类型； 0： 商承； 1： 银承


```json
{
  "acceptorAccountNum": "302",
  "acceptorName": "中信银行北京分行账务中心",
  "acceptorBank": "302100011995",
  "billType": "001",

  "receiveAccountNum": "8110701013601888650",
}
```

承兑人账号： code: acceptorAccountNum； showLabel: acceptorBankUnitedCode
trans: [

```python
//承兑人账号银行账号
String acceptorAccountNum = fmsBoeBillApplyApiDTO.getAcceptorAccountNum();
bankList.add(acceptorAccountNum);
if (StrUtil.equals(billType, cn.ztessc.common.enums.EnumType.BillTypeCode.SIGN_BILL.getCode())) {
    // 银行
    acceptorType = BillInstructionsType.ACCEOPTOR_TYPE.STATUS_1.getCode();
}else if (StrUtil.equals(billType, cn.ztessc.common.enums.EnumType.BillTypeCode.PAY_BILL.getCode())){
    // 商业
    acceptorType = BillInstructionsType.ACCEOPTOR_TYPE.STATUS_0.getCode();
}
boeBillApply.setAcceptorType(acceptorType);



//收票人银行账号
String receiveAccountNum = fmsBoeBillApplyApiDTO.getReceiveAccountNum();
vendors.add(receiveAccountNum);
Map<String, SysVendorsBankDTO> vendorBankListByAccountCode = fmsPayableCreditLetterService.getVendorBankListByAccountCode(vendors);
List<FmsAccountVDTO> accountByBankNumbers = fmsAccountService.findAccountByBankNumbers(bankList, groupId);


//银承 承兑人
FmsAccountVDTO accepFmsAccountVDTO = bankNumberMap.get(acceptorAccountNum);
if (StrUtil.equals(acceptorType, BillInstructionsType.ACCEOPTOR_TYPE.STATUS_1.getCode())) {
    if (ObjUtil.isNotNull(accepFmsAccountVDTO)) {
        //承兑人-承兑人账号
        boeBillApply.setAcceptorAccountNum(acceptorAccountNum);
        if (StrUtil.isBlank(fmsBoeBillApplyApiDTO.getAcceptorName())) {
            //承兑人-承兑人名称
            boeBillApply.setAcceptorName(accepFmsAccountVDTO.getAccountName());
        }
        if (StrUtil.isBlank(fmsBoeBillApplyApiDTO.getAcceptorBank())) {
            //承兑人-承兑人开户行
            boeBillApply.setAcceptorBank(accepFmsAccountVDTO.getOpenBankName());
        }
        boeBillApply.setAcceptorBankUnitedCode(accepFmsAccountVDTO.getUnitedCode());
    }
}

acceptorAccountNum：acceptorAccountNum
acceptorName: acceptorName ? accountVDTO::AccountName
acceptorBank: acceptorBank ? accountVDTO::OpenBankName
acceptorBankUnitedCode: accountVDTO::UnitedCode

// 商承 承兑人
if (StrUtil.equals(acceptorType, BillInstructionsType.ACCEOPTOR_TYPE.STATUS_1.getCode())) {
    // 联行号
    String acceptorBank = fmsBoeBillApplyApiDTO.getAcceptorBank();
    if (StrUtil.isNotBlank(acceptorBank)){
        // 查询合作银行联行号
        SimpleObjCacheDto payBankUnitedCacheDto = cacheUtil.findByCode(cn.ztessc.common.enums.EnumType.CacheDataType.BANKUNITED, acceptorBank, groupId);
        if (CacheUtil.isExistAndValidity(payBankUnitedCacheDto)) {
            SysBankUnitedCodeDTO bankUnitedCodeDTO = payBankUnitedCacheDto.getObj(SysBankUnitedCodeDTO.class);
            //承兑人-承兑人名称
            boeBillApply.setAcceptorName(fmsBoeBillApplyApiDTO.getAcceptorName());
            //承兑人-承兑人开户行
            boeBillApply.setAcceptorBank(bankUnitedCodeDTO.getBankName());
            boeBillApply.setAcceptorBankUnitedCode(bankUnitedCodeDTO.getUnitedCode());
        } else {
            throw new ZteException(MessageUtils.getMessage("fms.bank.code.invalid", acceptorBank));
        }
    }
}    
acceptorName: acceptorName 
acceptorBank: bankUnitedCodeDTO::BankName
acceptorBankUnitedCode: bankUnitedCodeDTO::UnitedCode
```
