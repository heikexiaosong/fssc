# 贷款台账管理


GUARANTEE_OCCUPANCY_NODE:   授信占用节点：0登记，1放款
COLLATERAL_OCCUPANCY_NODE:  担保占用节点: 

## 
http://127.0.0.1/fmsprovideheader
dto: 参数

1. 释放授信在途占用
```sql
-- 查询申请单id
select BOE_ID from FMS_BOE_LEDGER_HANDLE where id = dto::applyId
-- 释放单据在途
select * from FMS_CREDIT_TRANSIT_DETAIL where BOE_ID = ：boeId
```

2. 保存主数据： FMS_PROVIDE_HEADER

2. lpr调整日期
```sql
-- 删除旧的lpr调整日期数据
delete from FMS_PROVIDE_LPR_DATE where PROVIDE_ID = dto:id
-- lprAdjust == '0'：继续； 否则退出
-- TODO
```

3. 业务数据区记录【dataAreaList】
FMS_PROVIDE_BUS: 业务数据区记录保存 【provideHeaderId = result:id】

4. 授信金额占用：GUARANTEE_OCCUPANCY_NODE = "0"
limitUserd == "2"; 银行额度 才执行
FMS_BREED_CHILD_USE 授信品种占用记录保存
FMS_CREDIT_HEADER  授信已被占用,状态即修改为已生效
FMS_CREDIT_BREED_CHILD  增加授信子品种已占用额度
FMS_CREDIT_ALLOCATION_CHILD 增加授信分配子品种已占用余额、可用余额
FMS_CREDIT_HEADER 更新授信头表汇总金额

5. 占用担保: COLLATERAL_OCCUPANCY_NODE = "0"
FMS_INTERNAL_GUARANTEE: 对内担保信息查询
FMS_GUARANTEE_USE: 担保占用记录保存
FMS_GUARANTEE_USAGE: 担保占用金额表
FMS_INTERNAL_GUARANTEE: 更新担保占用额度


6. 保存附件
FMS_ATTACHMENT： 保存附件记录

7. 登记即放款
FMS_PROVIDE_LOAN: 贷款放款表保存
FMS_TRANSACTION_DETAILS_BUS: 放款信息-流水-交易明细业务关联表
FMS_PROVIDE_REPAY_PLAN： 放款的计划信息
FMS_PROVIDE_PLAN_REL: 放还款计划关联表

FMS_LOAN_INTEREST_RECORD: 利率调整记录表
FMS_LOAN_RATE_COMPUTE: 利息计算表
FMS_TRANSACTION_DETAILS_LABLE: 交易明细业标签表 

7.1 生成内部户明细账: INTERNAL_DETAIL_LEDGER == "Y"
FMS_INTERIOR_DETAIL: 内部户明细账保存【放款金额为借方金额， 贷方为0】
```sql
select *
from fms_account_mapping m 
     inner join fms_account o on m.OUT_ACCOUNT_ID = o.id
     inner join fms_inner_account i on m.INNER_ACCOUNT_ID = i.id
```
