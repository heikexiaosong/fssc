1. FMS_INNER_LOAN_LEDGER 内部借款台账变
2. FMS_INNER_LOAN_LEDGER_RECORD 内部借款台账变更表，包括 放款 还款 利率变更记录 等等
3. fms_transaction_details_bus
4. fms_transaction_details_lable


- 正常利率-展期利率-罚息利率， 展期和罚息重叠，优先展示展期，展期不一定有值，正常利率和罚息利率在新增借款台账时插入，必有值
- 还款日期不能大于内部借款合同到期日期
- 若内部借款有展期，则校验还款日期不能大于内部借款展期最大到期日期
- 校验还款日期不能小于内部借款放款日期
- 还款日期小于当前放款预提截止日，不允许编辑
- 还款本金不能小于0
- 还款本金不能大于借款放款的待还款金额

```sql
-- 查询可能关联得流水
select *
  from fms_transaction_details_his d
 where 1 = 1
        and d.group_id = 'ba2ad44f9aba2ad54fa43139322e0000'
        and d.validity_flag = '0'
        and d.enabled_flag = '0'
        and d.transaction_date >= TIMESTAMP '2026-06-09 00:00:00.000'
        and d.transaction_date <= TIMESTAMP '2026-06-09 23:59:59.000'
        and d.transaction_type = '1'
        and transaction_amount = 45000000
        and transaction_currency_code = 'CNY'
        and not exists (
                select 1
                from fms_transaction_details_bus b
                where d.fms_business_no = b.fms_business_no
                        and b.enabled_flag = '0'
                        and b.validity_flag = '0'
                        and b.bus_type = '2'
        )
        and not exists (
                select 1
                from fms_transaction_details_lable b
                where d.fms_business_no = b.fms_business_no
                        and b.enabled_flag = '0'
                        and b.validity_flag = '0'
        )
limit 10
```

```sql

FROM zfs_fms.fms_transaction_details_his t
WHERE FMS_BUSINESS_NO = 'd0f29f0e3ceb0f78f9c293f66a198bae37846184ff3ff7d51e982e902b81dde7';


SELECT t.id, t.RECEIPT_NO, t.BATCH_NUMBER, t.BATCH_NUMBER_SYS, t.TOUFO
FROM zfs_fms.fms_electronic_receipt t
WHERE RECEIPT_NO = 'NDEwMTE2NDUyOTQ='


select t.id as 'detail_id', t.TRANSACTION_NO,  t.FMS_BUSINESS_NO, t.BILL_RECEIPT_ID, t.BILL_RECEIPT_NO, t.BILL_RECEIPT_URL
, e.id as 'receipt_id',  e.RECEIPT_NO,  e.SYNC_FILE_URL, e.BATCH_NUMBER_SYS
from fms_transaction_details_his t
    left join fms_electronic_receipt e on e.RECEIPT_NO = t.BILL_RECEIPT_NO
where t.ENABLED_FLAG = '0'
 and (t.BILL_RECEIPT_NO is not null and t.BILL_RECEIPT_NO <> '')
and t.id = 'c50da509b9aff329fb5e3139322e629b'

```
